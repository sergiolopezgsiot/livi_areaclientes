# LIVI · Área de Clientes (`livi_areaclientes`)

Aplicación web y API independiente para el Área de Clientes de LIVI.

## Requisitos y Configuración

1. Copiar `.env.example` a `.env` con las credenciales de base de datos MySQL y variables de entorno.
2. Instalar dependencias:
   ```bash
   pnpm install
   # o npm install
   ```
3. Iniciar el servidor:
   ```bash
   pnpm start
   # o npm start
   ```

El área de clientes estará disponible en `http://localhost:3000/` (y `http://localhost:3000/clientes`).
